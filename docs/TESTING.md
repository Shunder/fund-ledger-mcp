## 本地试用与客户端实录

- 从空 npm 缓存安装锁定依赖，Node 24 环境下安装用时 2.88 秒，运行演示用时 4.44 秒。首次下载耗时受网络影响。
- 标准 SDK 的 stdio 测试实际启动独立内存数据库，校验工具发现、净值回放、QDII 缺数、XIRR、回撤、预览前后状态、重复确认、按平台及转换两侧代码筛选、重启清空演示流水。
- 分红测试覆盖同一只基金在两个平台分别现金分红和红利再投、份额舍入、应收红利、除息后卖光、周末到账，以及只有一个平台补录或有份额折算时的缺失状态。
- 在 `@deepseek-ai/dsh 0.2.2-rc.5` 的 Web 界面加载本仓库的 stdio 配置，实际发现 19 个演示工具。通过本机测试接口由 Codex 提供回复，Harness 执行同步、业绩查询、定投预览、确认及写后查询。README 三图为这些会话的浏览器截图。远程 Harness 配置通过 CLI 合并检查；本次没有以真实访问令牌在 Harness 中读取私人账本，也未调用 DeepSeek 商业模型 API。通用客户端 JSON 已生成，Claude Desktop 与 VS Code 图形界面未单独验收。
